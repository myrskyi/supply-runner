# Treasure Map

An AI scout that maps a small business's local competitors and shows where the money is. It learns from feedback and checks its own past predictions, so it gets better every day.

Built by team πrates at "AI Agents for the Rest of Us" (AI Tinkerers Prague, 2026-11-13) with Apify, Featherless and PostHog.

## Start here

- Concept and open decisions: [docs/idea.md](docs/idea.md)
- Plan and owners: [docs/plan.md](docs/plan.md)
- Decision log: [docs/decisions.md](docs/decisions.md)

## Setup

```bash
cp .env.example .env
```

Fill in the keys locally. Never commit `.env`.
